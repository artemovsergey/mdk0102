# Практическая работа 27. Интеграционный тест сервиса с базой данных SQLite

### **Тема**
Интеграционное тестирование сервисного класса в связке с настоящей реляционной базой данных. Настройка базы данных SQLite в режиме in-memory и проверка работы сервиса с EF Core с помощью xUnit.

### **Цель**
Сформировать практические навыки интеграционного тестирования:
*   Понимание разницы между юнит-тестами и интеграционными тестами.
*   Настройка тестовой базы данных SQLite в оперативной памяти (`DataSource=:memory:`).
*   Создание схемы базы данных в тестах с помощью `EnsureCreated()`.
*   Организация жизненного цикла тестового класса через конструктор и `IDisposable`.
*   Проверка реальных сценариев работы с БД: сохранение, чтение, изменение, удаление данных.
*   Проверка исключений и ограничений базы данных (уникальный индекс).

### **Теоретическая часть**

**Интеграционный тест** — это тест, который проверяет совместную работу нескольких компонентов системы. В отличие от юнит-теста, который проверяет отдельный метод в изоляции (со «заглушками» вместо зависимостей), интеграционный тест использует настоящие зависимости. В этой работе мы будем тестировать сервис (`LibraryService`) в связке с настоящей базой данных: EF Core + SQLite.

**Пирамида тестирования** (в порядке увеличения «стоимости» теста):
*   **Юнит-тесты** (много, быстрые) — проверяют отдельные классы и методы без внешних зависимостей.
*   **Интеграционные тесты** (меньше, медленнее) — проверяют взаимодействие компонентов: сервис + БД, сервис + HTTP-клиент и т.п.
*   **E2E-тесты** (единицы, самые медленные) — проверяют систему целиком через пользовательский интерфейс или API.

**Почему не подходит in-memory провайдер EF Core (`Microsoft.EntityFrameworkCore.InMemory`)?**
*   Это **не реляционная СУБД**: он не выполняет SQL-запросы и не проверяет ограничения базы данных (уникальные индексы, внешние ключи, типы и длины строк). Из-за этого ошибки, которые обязательно возникнут в реальной PostgreSQL или SQL Server, в таких тестах могут «не заметиться». Для интеграционных тестов нужна настоящая СУБД — хотя бы в лёгком варианте.

**SQLite in-memory** — компактная встраиваемая реляционная СУБД, которая отлично подходит для тестов:
*   Строка подключения `DataSource=:memory:` создаёт базу данных в оперативной памяти.
*   База данных **существует, пока открыто хотя бы одно соединение**. Если все соединения закрыты — база уничтожается. Поэтому в тестах мы создаём и **открываем** объект `SqliteConnection` в конструкторе тестового класса и закрываем его только в `Dispose()` — держим соединение «живым» на всё время теста.
*   `EnsureCreated()` создаёт схему базы данных по модели EF Core (таблицы, индексы). Миграции в тестах не нужны.
*   Каждый тест получает **чистую базу данных**, потому что xUnit создаёт **новый экземпляр тестового класса перед каждым тестовым методом**. Это обеспечивает изоляцию тестов друг от друга.

**Используемые инструменты и версии:**
*   .NET 10 (LTS), проекты `net10.0`;
*   EF Core 10, пакет `Microsoft.EntityFrameworkCore.Sqlite` версии `10.0.12`;
*   фреймворк тестирования xUnit 2.9.3.

**Схема интеграционного теста:**
1.  **Arrange (Подготовка):** создание подключения к SQLite, контекста EF Core, схемы БД (`EnsureCreated()`), создание сервиса.
2.  **Act (Действие):** вызов метода сервиса.
3.  **Assert (Проверка):** проверка результата через запрос к базе данных или проверка выброшенного исключения.

### **Практический пример**

**Задание:** сервис «Библиотека книг». Книгу можно добавить (ISBN должен быть уникальным), получить список всех книг (отсортированный по названию), выдать книгу и удалить её (выданную книгу удалять нельзя).

**1. Сущность (`LibraryApp/Book.cs`):**

```csharp
namespace LibraryApp;

public class Book
{
    public Guid Id { get; set; } = Guid.NewGuid();
    public string Title { get; set; } = string.Empty;
    public string Author { get; set; } = string.Empty;
    public string Isbn { get; set; } = string.Empty;
    public bool IsBorrowed { get; set; }
}
```

**2. Контекст базы данных (`LibraryApp/LibraryDbContext.cs`):**

```csharp
using Microsoft.EntityFrameworkCore;

namespace LibraryApp;

public class LibraryDbContext : DbContext
{
    public LibraryDbContext(DbContextOptions<LibraryDbContext> options)
        : base(options) { }

    public DbSet<Book> Books => Set<Book>();

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<Book>(entity =>
        {
            entity.ToTable("books");
            entity.HasKey(b => b.Id);
            entity.Property(b => b.Title).HasMaxLength(200).IsRequired();
            entity.Property(b => b.Author).HasMaxLength(150).IsRequired();
            entity.Property(b => b.Isbn).HasMaxLength(20).IsRequired();
            entity.HasIndex(b => b.Isbn).IsUnique();
        });
    }
}
```

**3. Сервис (`LibraryApp/LibraryService.cs`):**

```csharp
using Microsoft.EntityFrameworkCore;

namespace LibraryApp;

public class LibraryService
{
    private readonly LibraryDbContext _context;

    public LibraryService(LibraryDbContext context)
    {
        _context = context;
    }

    public async Task<Book> AddBookAsync(Book book)
    {
        if (await _context.Books.AnyAsync(b => b.Isbn == book.Isbn))
        {
            throw new InvalidOperationException($"Книга с ISBN {book.Isbn} уже есть в библиотеке.");
        }

        _context.Books.Add(book);
        await _context.SaveChangesAsync();
        return book;
    }

    public async Task<List<Book>> GetAllBooksAsync() =>
        await _context.Books.AsNoTracking().OrderBy(b => b.Title).ToListAsync();

    public async Task BorrowBookAsync(Guid id)
    {
        var book =
            await _context.Books.FindAsync(id) ?? throw new KeyNotFoundException("Книга не найдена.");

        if (book.IsBorrowed)
        {
            throw new InvalidOperationException("Книга уже выдана.");
        }

        book.IsBorrowed = true;
        await _context.SaveChangesAsync();
    }

    public async Task DeleteBookAsync(Guid id)
    {
        var book =
            await _context.Books.FindAsync(id) ?? throw new KeyNotFoundException("Книга не найдена.");

        if (book.IsBorrowed)
        {
            throw new InvalidOperationException("Нельзя удалить выданную книгу.");
        }

        _context.Books.Remove(book);
        await _context.SaveChangesAsync();
    }
}
```

**4. Интеграционные тесты (`LibraryApp.Tests/LibraryServiceTests.cs`):**

Обратите внимание на конструктор: он выполняется **перед каждым тестом**, поэтому каждый тест работает с новой пустой базой данных. Соединение `SqliteConnection` не закрывается до вызова `Dispose()` — иначе база данных в памяти исчезнет.

```csharp
using LibraryApp;
using Microsoft.Data.Sqlite;
using Microsoft.EntityFrameworkCore;

namespace LibraryApp.Tests;

public class LibraryServiceTests : IDisposable
{
    private readonly SqliteConnection _connection;
    private readonly LibraryDbContext _context;
    private readonly LibraryService _service;

    public LibraryServiceTests()
    {
        _connection = new SqliteConnection("DataSource=:memory:");
        _connection.Open();

        var options = new DbContextOptionsBuilder<LibraryDbContext>().UseSqlite(_connection).Options;

        _context = new LibraryDbContext(options);
        _context.Database.EnsureCreated();

        _service = new LibraryService(_context);
    }

    public void Dispose()
    {
        _context.Dispose();
        _connection.Dispose();
    }

    [Fact]
    public async Task AddBookAsync_ValidBook_SavesToDatabase()
    {
        var book = new Book
        {
            Title = "CLR via C#",
            Author = "Джеффри Рихтер",
            Isbn = "978-5-496-01202-5",
        };

        await _service.AddBookAsync(book);

        Assert.Equal(1, await _context.Books.CountAsync());
        Assert.Equal("CLR via C#", (await _context.Books.SingleAsync()).Title);
    }

    [Theory]
    [InlineData("978-5-496-01202-5")]
    [InlineData("9780132350884")]
    [InlineData("978-0-201-63361-0")]
    public async Task AddBookAsync_ValidIsbnFormats_SavesBook(string isbn)
    {
        var book = new Book
        {
            Title = "Книга",
            Author = "Автор",
            Isbn = isbn,
        };

        await _service.AddBookAsync(book);

        Assert.Equal(isbn, (await _context.Books.SingleAsync()).Isbn);
    }

    [Fact]
    public async Task AddBookAsync_DuplicateIsbn_ThrowsInvalidOperationException()
    {
        await _service.AddBookAsync(
            new Book
            {
                Title = "Книга 1",
                Author = "Автор 1",
                Isbn = "978-5-000-00001-1",
            }
        );

        var duplicate = new Book
        {
            Title = "Книга 2",
            Author = "Автор 2",
            Isbn = "978-5-000-00001-1",
        };

        await Assert.ThrowsAsync<InvalidOperationException>(() => _service.AddBookAsync(duplicate));
    }

    [Fact]
    public async Task GetAllBooksAsync_ReturnsBooksSortedByTitle()
    {
        await _service.AddBookAsync(
            new Book
            {
                Title = "Язык программирования C#",
                Author = "Автор 1",
                Isbn = "111",
            }
        );
        await _service.AddBookAsync(
            new Book
            {
                Title = "Алгоритмы",
                Author = "Автор 2",
                Isbn = "222",
            }
        );

        var books = await _service.GetAllBooksAsync();

        Assert.Equal(new[] { "Алгоритмы", "Язык программирования C#" }, books.Select(b => b.Title));
    }

    [Fact]
    public async Task BorrowBookAsync_AvailableBook_MarksAsBorrowed()
    {
        var book = new Book
        {
            Title = "Книга",
            Author = "Автор",
            Isbn = "333",
        };
        await _service.AddBookAsync(book);

        await _service.BorrowBookAsync(book.Id);

        Assert.True((await _context.Books.FindAsync(book.Id))!.IsBorrowed);
    }

    [Fact]
    public async Task BorrowBookAsync_AlreadyBorrowed_ThrowsInvalidOperationException()
    {
        var book = new Book
        {
            Title = "Книга",
            Author = "Автор",
            Isbn = "444",
        };
        await _service.AddBookAsync(book);
        await _service.BorrowBookAsync(book.Id);

        await Assert.ThrowsAsync<InvalidOperationException>(() => _service.BorrowBookAsync(book.Id));
    }

    [Fact]
    public async Task DeleteBookAsync_BorrowedBook_ThrowsInvalidOperationException()
    {
        var book = new Book
        {
            Title = "Выданная книга",
            Author = "Автор",
            Isbn = "555",
        };
        await _service.AddBookAsync(book);
        await _service.BorrowBookAsync(book.Id);

        await Assert.ThrowsAsync<InvalidOperationException>(() => _service.DeleteBookAsync(book.Id));
    }

    [Fact]
    public async Task IsbnUniqueIndex_DuplicateInsert_ThrowsDbUpdateException()
    {
        await _service.AddBookAsync(
            new Book
            {
                Title = "Книга 1",
                Author = "Автор 1",
                Isbn = "666",
            }
        );

        _context.Books.Add(
            new Book
            {
                Title = "Книга 2",
                Author = "Автор 2",
                Isbn = "666",
            }
        );

        await Assert.ThrowsAsync<DbUpdateException>(() => _context.SaveChangesAsync());
    }
}
```

### **Варианты заданий**

Студент выбирает вариант, соответствующий его номеру в журнале. Если студентов больше, чем вариантов, преподаватель назначает индивидуальную предметную область (свои сущность, поля и операции).

**Вариант 1. Библиотека книг** (пример из работы).
Сущность `Book`: `Title`, `Author`, `Isbn`, `IsBorrowed`. Уникальный индекс по `Isbn`.
Операции: `AddBookAsync` (дубликат ISBN — исключение), `GetAllBooksAsync` (сортировка по названию), `BorrowBookAsync` (повторная выдача — исключение), `DeleteBookAsync` (удаление выданной книги запрещено).

**Вариант 2. Склад товаров.**
Сущность `Product`: `Name`, `Sku` (артикул), `Quantity` (остаток), `Price`. Уникальный индекс по `Sku`.
Операции: `AddProductAsync` (дубликат артикула — исключение), `GetAllProductsAsync` (сортировка по названию), `WriteOffAsync(id, count)` (списание: нельзя списать больше остатка, остаток не может стать отрицательным), `DeleteProductAsync` (нельзя удалить товар с ненулевым остатком).

**Вариант 3. Учёт студентов.**
Сущность `Student`: `FullName`, `RecordBookNumber` (номер зачётки), `GroupName`, `HasDebt` (академическая задолженность). Уникальный индекс по `RecordBookNumber`.
Операции: `AddStudentAsync` (дубликат номера зачётки — исключение), `GetAllStudentsAsync` (сортировка по ФИО), `ClearDebtAsync` (если задолженности нет — исключение), `DeleteStudentAsync` (нельзя отчислить студента с задолженностью).

**Вариант 4. Кинотеатр.**
Сущность `Ticket`: `MovieTitle`, `SeatNumber`, `Price`, `IsSold`. Составной уникальный индекс по паре (`MovieTitle`, `SeatNumber`) — на один сеанс место продаётся один раз.
Операции: `AddTicketAsync` (дубликат места на сеанс — исключение), `GetAllTicketsAsync` (сортировка по названию фильма, затем по номеру места), `SellTicketAsync` (повторная продажа — исключение), `DeleteTicketAsync` (нельзя удалить проданный билет).

# Практическая работа №27: Интеграционный тест сервиса с базой данных SQLite

**Вариант: 1**

**Задание:**
Реализовать сервис «Библиотека книг»: добавление книги (ISBN уникален), получение списка книг
с сортировкой по названию, выдача книги, удаление книги (выданную удалять нельзя).
Написать интеграционные тесты с использованием SQLite in-memory.

**Используемые технологии:**
- .NET 10, EF Core 10 (Microsoft.EntityFrameworkCore.Sqlite 10.0.12)
- xUnit 2.9.3
- База данных SQLite в режиме in-memory (`DataSource=:memory:`)

**Код тестов (фрагмент):**

```csharp
// LibraryApp.Tests/LibraryServiceTests.cs
public LibraryServiceTests()
{
    _connection = new SqliteConnection("DataSource=:memory:");
    _connection.Open();

    var options = new DbContextOptionsBuilder<LibraryDbContext>().UseSqlite(_connection).Options;

    _context = new LibraryDbContext(options);
    _context.Database.EnsureCreated();

    _service = new LibraryService(_context);
}
```
