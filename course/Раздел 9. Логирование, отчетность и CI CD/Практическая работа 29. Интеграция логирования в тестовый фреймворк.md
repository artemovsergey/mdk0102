# Практическая работа 29. Интеграция логирования в тестовый фреймворк

### **Тема**

Интеграция структурированного логирования (Serilog) в проект интеграционных тестов: собственный приёмник событий для `ITestOutputHelper`, вывод логов в консоль и в отчёт о тестировании.

### **Цель**

- Подключить Serilog в существующий тестовый проект, созданный в Практической работе 27.
- Настроить логгер уровня класса тестов вместо глобального `Log.Logger`.
- Написать собственный приёмник (sink), направляющий события Serilog в вывод xUnit.
- Добавить осмысленные логи в тесты: шаги сценария, ожидаемые ошибки, количество записей.
- Убедиться, что логи видны при прогоне тестов и попадают в отчёт упавшего теста.

### **Теоретическая часть**

**Зачем логировать тесты.** В лабораторной работе тест падает у вас на глазах — можно посмотреть и поправить. В реальном проекте тесты падают в CI на чужой машине, и единственный источник информации — лог прогона. Структурированные логи Serilog сохраняют данные отдельными свойствами (`Title`, `Isbn`), а не текстом, поэтому по ним можно фильтровать и искать причины.

**`ITestOutputHelper`.** xUnit не перехватывает `Console.WriteLine`: вывод, сделанный этим способом, нигде не сохраняется. Для вывода из теста используется интерфейс `ITestOutputHelper`, который xUnit передаёт в конструктор класса тестов. Его записи попадают в отчёт о тестировании (TRX) — правда, только у **упавших** тестов: для успешных VSTest вывод не сохраняет. Поэтому логи тестов принято направлять сразу в два места:

1. в **консоль** — строки видны в общем выводе `dotnet test` всегда;
2. в **`ITestOutputHelper`** — при падении теста лог окажется в TRX рядом с сообщением об ошибке.

**Почему логгер создаётся в конструкторе класса, а не через `Log.Logger`.** xUnit запускает классы тестов параллельно. Глобальный статический логгер смешал бы записи всех тестов в один поток — непонятно, какое сообщение какому тесту принадлежит. Поэтому в каждом тестовом классе создаётся **свой** экземпляр `ILogger`, в который добавляется sink с `ITestOutputHelper` именно этого класса.

**Какую информацию логировать.** Шаги сценария и данные — `Information`; детали, нужные только при отладке, — `Debug`; ожидаемые ошибки (тест проверяет, что исключение будет выброшено) — `Warning`, чтобы при чтении лога было ясно: ошибка не случайна, а предусмотрена сценарием.

**Приёмник (sink) — это класс.** `ILogEventSink` содержит единственный метод `Emit(LogEvent)`. Любой класс с этим методом можно подключить через `.WriteTo.Sink(...)`. Мы напишем собственный sink для xUnit: он получит `ITestOutputHelper` и будет писать отформатированные строки.

**Файл `LibraryApp.Tests/XunitOutputSink.cs`:**

```csharp
using Serilog.Core;
using Serilog.Events;
using Xunit.Abstractions;

namespace LibraryApp.Tests;

/// <summary>Sink, который выводит события Serilog в отчёт xUnit.</summary>
public class XunitOutputSink : ILogEventSink
{
    private readonly ITestOutputHelper _output;

    public XunitOutputSink(ITestOutputHelper output) => _output = output;

    public void Emit(LogEvent logEvent)
    {
        _output.WriteLine($"[{logEvent.Level:u3}] {logEvent.RenderMessage()}");

        if (logEvent.Exception is not null)
        {
            _output.WriteLine(logEvent.Exception.ToString());
        }
    }
}
```

Разбор кода:

- `ILogEventSink` — интерфейс приёмника Serilog с единственным методом `Emit`;
- в конструктор передаётся `ITestOutputHelper` того тестового класса, который создал sink;
- `logEvent.RenderMessage()` подставляет значения свойств в шаблон сообщения;
- `logEvent.Level:u3` — сокращённый уровень (`INF`, `WRN`, `ERR`);
- если у события есть исключение, оно выводится полным стеком — это важно для диагностики.

**Файл `LibraryApp.Tests/LibraryServiceTests.cs` (целиком, с логированием):**

```csharp
using LibraryApp;
using Microsoft.Data.Sqlite;
using Microsoft.EntityFrameworkCore;
using Serilog;
using Xunit.Abstractions;

namespace LibraryApp.Tests;

public class LibraryServiceTests : IDisposable
{
    private readonly SqliteConnection _connection;
    private readonly LibraryDbContext _context;
    private readonly LibraryService _service;
    private readonly ILogger _logger;

    public LibraryServiceTests(ITestOutputHelper output)
    {
        _logger = new LoggerConfiguration()
            .MinimumLevel.Debug()
            .WriteTo.Console()
            .WriteTo.Sink(new XunitOutputSink(output))
            .CreateLogger();

        _connection = new SqliteConnection("DataSource=:memory:");
        _connection.Open();

        var options = new DbContextOptionsBuilder<LibraryDbContext>().UseSqlite(_connection).Options;

        _context = new LibraryDbContext(options);
        _context.Database.EnsureCreated();

        _service = new LibraryService(_context);
    }

    public void Dispose()
    {
        _context.Dispose();
        _connection.Dispose();
    }

    [Fact]
    public async Task AddBookAsync_ValidBook_SavesToDatabase()
    {
        var book = new Book
        {
            Title = "CLR via C#",
            Author = "Джеффри Рихтер",
            Isbn = "978-5-496-01202-5",
        };

        _logger.Information("Добавляем книгу {Title} (ISBN {Isbn})", book.Title, book.Isbn);

        await _service.AddBookAsync(book);

        _logger.Information("Книг в базе после добавления: {Count}", await _context.Books.CountAsync());

        Assert.Equal(1, await _context.Books.CountAsync());
        Assert.Equal("CLR via C#", (await _context.Books.SingleAsync()).Title);
    }

    [Theory]
    [InlineData("978-5-496-01202-5")]
    [InlineData("9780132350884")]
    [InlineData("978-0-201-63361-0")]
    public async Task AddBookAsync_ValidIsbnFormats_SavesBook(string isbn)
    {
        var book = new Book
        {
            Title = "Книга",
            Author = "Автор",
            Isbn = isbn,
        };

        await _service.AddBookAsync(book);

        Assert.Equal(isbn, (await _context.Books.SingleAsync()).Isbn);
    }

    [Fact]
    public async Task AddBookAsync_DuplicateIsbn_ThrowsInvalidOperationException()
    {
        await _service.AddBookAsync(
            new Book
            {
                Title = "Книга 1",
                Author = "Автор 1",
                Isbn = "978-5-000-00001-1",
            }
        );

        var duplicate = new Book
        {
            Title = "Книга 2",
            Author = "Автор 2",
            Isbn = "978-5-000-00001-1",
        };

        _logger.Warning("Ожидаем ошибку дубликата ISBN {Isbn}", duplicate.Isbn);

        await Assert.ThrowsAsync<InvalidOperationException>(() => _service.AddBookAsync(duplicate));
    }

    [Fact]
    public async Task GetAllBooksAsync_ReturnsBooksSortedByTitle()
    {
        await _service.AddBookAsync(
            new Book
            {
                Title = "Язык программирования C#",
                Author = "Автор 1",
                Isbn = "111",
            }
        );
        await _service.AddBookAsync(
            new Book
            {
                Title = "Алгоритмы",
                Author = "Автор 2",
                Isbn = "222",
            }
        );

        var books = await _service.GetAllBooksAsync();

        Assert.Equal(new[] { "Алгоритмы", "Язык программирования C#" }, books.Select(b => b.Title));
    }

    [Fact]
    public async Task BorrowBookAsync_AvailableBook_MarksAsBorrowed()
    {
        var book = new Book
        {
            Title = "Книга",
            Author = "Автор",
            Isbn = "333",
        };
        await _service.AddBookAsync(book);

        await _service.BorrowBookAsync(book.Id);

        Assert.True((await _context.Books.FindAsync(book.Id))!.IsBorrowed);
    }

    [Fact]
    public async Task BorrowBookAsync_AlreadyBorrowed_ThrowsInvalidOperationException()
    {
        var book = new Book
        {
            Title = "Книга",
            Author = "Автор",
            Isbn = "444",
        };
        await _service.AddBookAsync(book);
        await _service.BorrowBookAsync(book.Id);

        await Assert.ThrowsAsync<InvalidOperationException>(() => _service.BorrowBookAsync(book.Id));
    }

    [Fact]
    public async Task DeleteBookAsync_BorrowedBook_ThrowsInvalidOperationException()
    {
        var book = new Book
        {
            Title = "Выданная книга",
            Author = "Автор",
            Isbn = "555",
        };
        await _service.AddBookAsync(book);
        await _service.BorrowBookAsync(book.Id);

        await Assert.ThrowsAsync<InvalidOperationException>(() => _service.DeleteBookAsync(book.Id));
    }

    [Fact]
    public async Task IsbnUniqueIndex_DuplicateInsert_ThrowsDbUpdateException()
    {
        await _service.AddBookAsync(
            new Book
            {
                Title = "Книга 1",
                Author = "Автор 1",
                Isbn = "666",
            }
        );

        _context.Books.Add(
            new Book
            {
                Title = "Книга 2",
                Author = "Автор 2",
                Isbn = "666",
            }
        );

        await Assert.ThrowsAsync<DbUpdateException>(() => _context.SaveChangesAsync());
    }
}
```
