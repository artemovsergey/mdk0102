# Экзамен по МДК 01.02 Поддержка и тестирование программных модулей

Задания выполняются на C# (.NET 10). Для тестов используется xUnit (`[Fact]`, `[Theory]`/`[InlineData]`, ассерты `Assert.*`), для изоляции зависимостей — Moq. Все методы и свойства именуются в PascalCase.

1.  **Калькулятор (сложение).** Напишите метод `Add(int a, int b)`, возвращающий сумму двух чисел. Напишите тесты, проверяющие: сложение двух положительных чисел, положительного и отрицательного, двух нулей. Используйте `Assert.Equal` (при желании — `[Theory]` с `[InlineData]`).

2.  **Чётность числа.** Напишите метод `IsEven(int n)`, возвращающий `true`, если число чётное. Добавьте тесты для чётного положительного, нечётного положительного, чётного отрицательного, нуля и большого чётного числа. Используйте `Assert.True` / `Assert.False`.

3.  **Максимум из двух.** Напишите метод `MaxOfTwo(int a, int b)`, находящий большее из двух чисел. Протестируйте случаи: `a > b`, `a < b`, `a == b`, отрицательные числа.

4.  **Конвертер температуры.** Напишите метод `CelsiusToFahrenheit(double c)`, конвертирующий градусы Цельсия в Фаренгейты по формуле `F = C * 9 / 5 + 32`. Протестируйте: 0°C (должно получиться 32°F), 100°C, отрицательное значение и точность вычисления (например, 37°C → 98.6°F, проверьте через перегрузку `Assert.Equal(expected, actual, precision)`).

5.  **Валидатор email (упрощённый).** Напишите метод `IsValidEmail(string email)`, возвращающий `true`, если строка содержит символ `@` и точку `.` после `@`. Напишите тесты для валидного адреса, адреса без `@`, адреса без точки, пустой строки.

6.  **Реверс строки.** Напишите метод `ReverseString(string s)`, возвращающий перевёрнутую строку. Протестируйте: обычное слово, палиндром (например, «топот»), строку с пробелами, пустую строку, строку из одного символа.

7.  **Подсчёт гласных.** Напишите метод `CountVowels(string s)`, возвращающий количество гласных букв (а, е, ё, и, о, у, ы, э, ю, я) в строке без учёта регистра. Протестируйте на строке без гласных, только с гласными, смешанной, пустой, строке с заглавными гласными.

8.  **Поиск в массиве.** Напишите метод `FindIndex(int[] arr, int target)`, возвращающий индекс первого вхождения `target` в массив `arr` или `-1`, если элемент не найден. Протестируйте: элемент в начале, в конце, в середине, отсутствующий элемент, пустой массив.

9.  **Фильтрация массива.** Напишите метод `FilterEven(int[] numbers)`, возвращающий новый массив, содержащий только чётные числа из исходного. Протестируйте на массиве со смешанными числами, только нечётными, только чётными, пустом массиве.

10. **Самое длинное слово.** Напишите метод `LongestWord(string sentence)`, который принимает предложение и возвращает самое длинное слово в нём. Если таких слов несколько, верните первое. Протестируйте: предложение с одним словом, несколькими словами разной длины, словами одинаковой длины, пустую строку.

11. **Учётная запись пользователя.** Создайте класс `UserAccount` со свойствами `Username` (устанавливается в конструкторе) и `IsActive` (по умолчанию `true`). Напишите метод `Deactivate()`, устанавливающий `IsActive` в `false`. Напишите тесты, проверяющие: создание пользователя, начальное состояние `IsActive`, результат вызова `Deactivate()`.

12. **Корзина покупок.** Создайте класс `ShoppingCart`. Он должен иметь методы: `AddItem(string item, decimal price)` — добавление товара, `GetTotal()` — получение суммы и `Clear()`. Протестируйте: добавление одного товара, нескольких товаров, обнуление корзины после добавления.

13. **Статистика чисел.** Создайте класс `NumberStats`. Он должен иметь методы `AddNumber(double n)` и `GetStats()`, возвращающий кортеж `(double Min, double Max, double Avg)`. Протестируйте на последовательности положительных чисел, отрицательных, одном числе, а также на пустой последовательности (метод `GetStats()` должен бросить `InvalidOperationException`).

14. **Деление с безопасностью.** Напишите метод `SafeDivide(double a, double b)`, возвращающий результат деления `a / b`. Если `b` равен 0, метод должен вернуть `null` (или бросить `DivideByZeroException` — в зависимости от задания). Напишите тесты для успешного деления и деления на ноль.

15. **Парсер возраста.** Напишите метод `ParseAge(string ageStr)`, который преобразует строку в целое число (возраст). Если строка не является числом — бросается `FormatException`; если число вне диапазона 0–150 — `ArgumentOutOfRangeException`. Напишите тесты для валидной строки, нечисловой строки, отрицательного числа, слишком большого числа (используйте `Assert.Throws<T>`).

16. **Поиск файлов по расширению.** Напишите метод `FindFilesByExtension(List<string> filenames, string ext)`, который принимает список имён файлов и расширение (например, `".txt"`) и возвращает отфильтрованный список. Сравнение расширений — с учётом регистра. Протестируйте: обычное совпадение, отсутствие совпадений, пустой список, регистрозависимость.

17. **Параметризованный тест для калькулятора.** Напишите метод `Multiply(int a, int b)` (самостоятельно, он не связан с заданием 1). Составьте один параметризованный тест (`[Theory]` + `[InlineData]`), который проверяет: умножение на 0, умножение положительных чисел, умножение отрицательных чисел, а также коммутативность (`a * b == b * a`).

18. **Тест с фикстурами (setup/teardown).** Для класса `ShoppingCart` (задание 12) напишите тест-класс, в котором корзина с двумя предварительно добавленными товарами создаётся в конструкторе (в xUnit конструктор играет роль setup, а `IDisposable.Dispose()` — роль teardown). Затем напишите отдельные тесты для `GetTotal()` и `Clear()`, использующие эту предварительно заполненную корзину.

19. **Мок-объект (заглушка).** Напишите класс `WeatherService` с виртуальным методом `GetTemperature(string city)`, выполняющим «дорогой» HTTP-запрос. Создайте класс `TripPlanner`, зависящий от `WeatherService`. Напишите тест для `TripPlanner`, в котором `WeatherService` заменён моком (`Mock<WeatherService>` из Moq, настройка `Setup(...).Returns(...)`), возвращающим фиктивную температуру. Проверьте логику планирования поездки (например, «если > 20°C — едем в парк»).

20. **Тест временных интервалов.** Напишите метод `IsWeekend(DateTime date)`, возвращающий `true`, если это суббота или воскресенье. Напишите тесты с фиксированными датами для понедельника и субботы (например, `new DateTime(2026, 9, 21)` — понедельник, `new DateTime(2026, 9, 19)` — суббота). Дополнительно: протестируйте метод `GetDaysUntilNextMonday(DateTime date)`.
