# Экзамен по МДК 01.02 Поддержка и тестирование программных модулей

1.  **Калькулятор (Сложение).** Напишите функцию `add(a, b)`, которая возвращает сумму двух чисел. Создайте тесты, проверяющие: сложение двух положительных чисел, положительного и отрицательного, двух нулей.

2.  **Чётность числа.** Напишите функцию `is_even(n)`, возвращающую `True`, если число чётное. Протестируйте на чётном положительном, нечётном положительном, чётном отрицательном, нуле и большом чётном числе.

3.  **Максимум из двух.** Напишите функцию `max(a, b)`, находящую большее из двух чисел. Протестируйте случаи: `a > b`, `a < b`, `a == b`, отрицательные числа.

4.  **Конвертер температуры.** Напишите функцию `celsius_to_fahrenheit(c)`, конвертирующую градусы Цельсия в Фаренгейты по формуле `F = C * 9/5 + 32`. Протестируйте на: 0°C (должен быть 32°F), 100°C, отрицательном значении, точности вычисления (например, 37°C).

5.  **Валидатор email (упрощённый).** Напишите функцию `is_valid_email(email)`, которая возвращает `True`, если строка содержит символ `@` и точку `.` после `@`. Напишите тесты для валидного, email без `@`, email без точки, пустой строки.

6.  **Реверс строки.** Напишите функцию `reverse_string(s)`, возвращающую перевёрнутую строку. Протестируйте: обычное слово, палиндром (например, "топот"), строку с пробелами, пустую строку, строку из одного символа.

7.  **Подсчёт гласных.** Напишите функцию `count_vowels(s)`, которая возвращает количество гласных букв (а, е, ё, и, о, у, ы, э, ю, я) в строке без учёта регистра. Протестируйте на строке без гласных, только с гласными, смешанной, пустой, строке с заглавными гласными.

8.  **Поиск в массиве.** Напишите функцию `find_index(arr, target)`, возвращающую индекс первого вхождения `target` в массив `arr` или `-1`, если элемент не найден. Протестируйте: элемент в начале, в конце, в середине, отсутствующий элемент, пустой массив.

9.  **Фильтрация списка.** Напишите функцию `filter_even(numbers)`, возвращающую новый список, содержащий только чётные числа из исходного. Протестируйте на списке со смешанными числами, только нечётными, только чётными, пустом списке.

10. **Самое длинное слово.** Напишите функцию `longest_word(sentence)`, которая принимает предложение и возвращает самое длинное слово в нём. Если таких слов несколько, верните первое. Протестируйте предложение с одним словом, несколькими разной длины, с одинаковыми длинами, пустую строку.

11. **Учётная запись пользователя.** Создайте класс `UserAccount` с полями `username` (устанавливается при создании) и `is_active` (по умолчанию `True`). Напишите метод `deactivate()`, меняющий `is_active` на `False`. Напишите тесты, проверяющие: создание пользователя, начальное состояние `is_active`, вызов `deactivate()`.

12. **Корзина покупок.** Создайте класс `ShoppingCart`. Он должен иметь методы: `add_item(item, price)` для добавления товара, `get_total()` для получения суммы и `clear()`. Протестируйте: добавление одного товара, нескольких товаров, обнуление корзины после добавления.

13. **Статистика чисел.** Создайте класс `NumberStats`. Он должен иметь методы `add_number(n)` и `get_stats()`, который возвращает словарь `{"min": мин, "max": макс, "avg": среднее}`. Протестируйте на последовательности положительных чисел, отрицательных, одного числа, пустой последовательности (должен бросить исключение).


14. **Деление с безопасностью.** Напишите функцию `safe_divide(a, b)`, которая возвращает результат деления `a / b`. Если `b` равен 0, функция должна возвращать `None` (или бросать определённое исключение, в зависимости от задания). Напишите тесты для успешного деления и деления на ноль.

15. **Парсер возраста.** Напишите функцию `parse_age(age_str)`, которая преобразует строку в целое число (возраст). Если строка не является числом или число не в диапазоне 0-150, функция должна бросать исключение `ValueError`. Напишите тесты для валидной строки, нечисловой строки, отрицательного числа, слишком большого числа.

16. **Поиск файла по расширению.** Напишите функцию `find_files_by_extension(filenames, ext)`, которая принимает список имён файлов и расширение (например, ".txt") и возвращает отфильтрованный список. Расширение должно быть чувствительно к регистру. Протестируйте: обычное совпадение, отсутствие совпадений, пустой список, регистрозависимость.

17. **Параметризованный тест для калькулятора.** Возьмите функцию `multiply(a, b)` из задания 1 (или создайте её). Напишите один параметризованный тест, который проверяет умножение на 0, умножение положительных, отрицательных чисел и коммутативность (a*b = b*a).

18. **Тест с фикстурами (setup/teardown).** Для класса `ShoppingCart` (задание 12) напишите тест-класс, где в методе `setUp` создаётся новая корзина с двумя предустановленными товарами. Затем напишите отдельные тесты для `get_total()` и `clear()`, которые используют эту предварительно заполненную корзину.

19. **Мок-объект (заглушка).** Напишите класс `WeatherService`, который имеет метод `get_temperature(city)`, делающий "дорогой" HTTP-запрос. Создайте класс `TripPlanner`, который зависит от `WeatherService`. Напишите тест для `TripPlanner`, где `WeatherService` заменён моком/заглушкой, возвращающим фиктивную температуру. Проверьте логику планирования поездки (например, "если >20°C — едем в парк").

20. **Тест временных интервалов.** Напишите функцию `is_weekend(date)`, которая принимает объект даты и возвращает `True`, если это суббота или воскресенье. Напишите тесты, используя фиктивные даты для понедельника и субботы. Дополнительно: протестируйте функцию `get_days_until_next_monday(date)`.
