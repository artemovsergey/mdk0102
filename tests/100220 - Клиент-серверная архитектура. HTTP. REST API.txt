##05::3
Чем PUT отличается от PATCH?
PUT полностью обновляет ресурс, PATCH — частично
PUT создаёт ресурс, PATCH удаляет его
PUT неидемпотентен, PATCH идемпотентен
PUT используется только с JSON, PATCH только с XML

##08::3
В чём разница между кодами 401 Unauthorized и 403 Forbidden?
401 — требуется аутентификация, 403 — доступ запрещён
401 — доступ запрещён, 403 — требуется аутентификация
401 — ресурс не найден, 403 — ошибка сервера
Оба кода означают ошибку сервера

##10::3
Что означает принцип Stateless в HTTP?
Каждый запрос самодостаточен и не зависит от предыдущих
Сервер хранит все предыдущие запросы клиента
Клиент не может отправлять повторные запросы
Соединение всегда остаётся открытым
