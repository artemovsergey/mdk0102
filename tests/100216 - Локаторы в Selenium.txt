##13::3
В чём главное преимущество XPath согласно лекции?
Позволяет искать элементы по тексту и строить сложные условия
Всегда работает быстрее, чем ID
Не зависит от структуры HTML-документа
Поддерживает только поиск по атрибуту id
##14::3
В чём главный недостаток XPath согласно лекции?
Медленнее, чем ID и CSS Selector, сложнее читать и поддерживать
Не умеет искать элементы по атрибутам
Не может искать вложенные элементы
Не поддерживается современными браузерами
##15::3

Искать элементы по тегу, классу, ID, атрибутам и иерархии, включая вложенные
Искать элементы только по атрибуту id
Находить элементы только по видимому тексту
Автоматически изменять стили веб-страницы

##17::3
Почему локатор ID иногда считается ненадёжным?

Он не поддерживается методом FindElement
Поиск по ID всегда медленнее поиска по XPath
Он работает только в браузере Chrome
