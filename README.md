# МДК 01.02 Поддержка и тестирование программных модулей

Специальность: 09.02.07 «Информационные системы и программирование» (ИП)

Курс посвящён ручному и автоматизированному тестированию программных модулей на платформе .NET: от основ тест-дизайна — к юнит-тестам (xUnit, Moq), автоматизации веб-UI (Selenium WebDriver), тестированию REST API (RestSharp), интеграционным тестам с базой данных (EF Core + SQLite), нагрузочному тестированию (k6), логированию (Serilog) и непрерывной интеграции (GitHub Actions).

## Требования к окружению

- **.NET SDK 10** (LTS) — установка: `winget install Microsoft.DotNet.SDK.10`
- **VS Code** с расширением **C# Dev Kit** (панель Testing, Solution Explorer)
- **Git** — система контроля версий
- **Postman** — для практической работы 23 (анализ API)
- **Chrome или Edge** — для UI-тестов; для кросс-браузерного тестирования также Firefox
- **k6** — для нагрузочного тестирования (Раздел 8)
- Аккаунт **GitHub** — для Раздела 9 (непрерывная интеграция)
